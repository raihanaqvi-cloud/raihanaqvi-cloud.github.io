THE METHOD · How an investigation goes

  1. 01
    Find the real problem

    The reported complaint is rarely the problem. I follow it back to where it starts.

  2. 02
    Read the system

    Data models, states and permissions decide what an interface is allowed to be.

  3. 03
    Listen to everyone

    Support, engineering, sales and the operator each hold a piece of the answer.

  4. 04
    Ship the fix in stages

    A redesign that can’t be built incrementally isn’t a fix, it’s a wish.
